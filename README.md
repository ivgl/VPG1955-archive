# ВПИ 1955 — закрытый архив исходных материалов

Этот приватный репозиторий хранит исходные заявки, материалы событий, судейские документы и апелляции по годам. Он **не является каноническим состоянием** кампании. Единственный источник утверждённого мирового состояния: приватный `ivgl/VPG1955-state@main` (HEAD → манифест → JSON).

## Структура

- `turns/1955/posts/originals/` — неизменённые тексты заявок игроков.
- `turns/1955/posts/index.json` — реестр, Discord ID/ссылки, SHA-256, источник и права доступа.
- `turns/1955/events/` — подготовленные тексты событий с отдельным статусом (не игровые эффекты).
- `turns/1955/verdicts/` — литературные вердикты после появления.
- `turns/1955/appeals/` — апелляции и материалы рассмотрения.
- `turns/1955/decisions/` — утверждения администратора и ссылки на решения.

### Правила обработки

1. Оригиналы постов не редактировать; исправления сохранять отдельно, с ссылкой на оригинал.
2. Публикация файла **не означает** судейского решения, завершения проекта или принятия игровой дельты.
3. Секретные планы и индивидуальные события доступны только лицам с доступом к этому репозиторию. Права GitHub действуют на весь репозиторий, поэтому доступ нельзя автоматически делить по странам.
4. Ссылки на Discord предоставлены администратором; текст и автор сообщений не проверяются Discord API автоматически.
5. Не коммитить изменения канонических JSON сюда. Окончательный релиз — только `VPG1955-state` по `STATE_WORKFLOW.md`.
