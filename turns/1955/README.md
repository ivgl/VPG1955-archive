# Год 1955 — архив

- `posts/originals/`: пять сохранённых исходных текстов заявок.
- `posts/index.json`: Discord-ссылки и контрольные суммы SHA-256.
- `events/`: редакторские материалы и события; не является каноническим JSON.
- `verdicts/`: литературные вердикты после утверждения.
- `appeals/`: апелляции.
- `decisions/`: решения администратора и ссылки на эффект.

**Единственный источник состояния мира:** приватный `ivgl/VPG1955-state@main`. Архив не изменяет HEAD, фазу RECEIVING, ресурсы или бюджеты.
