# Вердикты 1955 года — приватный судейский архив

**Официально утверждённых и опубликованных вердиктов пока нет.** Во время `RECEIVING` материалы ниже существуют только как рабочие черновики. Ни одна численная дельта не применена к каноническому состоянию. Исходные посты хранятся отдельно и неизменно в `turns/1955/posts/originals/` (индекс `turns/1955/posts/index.json`).

- `drafts/JPN_1955_preliminary_dossier.md` — предыдущая литературная редакция, сохранена как история работы, **не использовать вместо актуальной**.

Два связанных политических ивента: `turns/1955/events/japan/JPN_1955_ELECTION_PARTIES_DRAFT.md` и `turns/1955/events/japan/JPN_RYUKYU_1955_PUBLICATION_DRAFT.md`. Оба зарегистрированы в `turns/1955/events/index.json` как `DRAFT`, не как опубликованные. Ивент по Рюкю требует отдельного решения о допустимом публичном раскрытии двустороннего материала.

**Дальнейший порядок:** администратор отдельно утверждает финальные вердикты, реакцию NPC, политические события и числовые эффекты; только затем через `STATE_WORKFLOW.md` готовится новый канонический выпуск `ivgl/VPG1955-state`. Не считать факт архивирования утверждением, переходом фазы или применением эффекта.
