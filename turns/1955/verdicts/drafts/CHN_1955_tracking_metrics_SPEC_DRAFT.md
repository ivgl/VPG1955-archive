# CHN 1955 — контрольные показатели аграрного поворота

**Статус:** DRAFT / DESIGN FOR LATER STATE INTEGRATION / NOT APPROVED / NOT APPLIED
**Связанные источники:** `INTAKE-1955-CHN-AGR-01`, `CHN_1955_agrarian_literary_PRELIMINARY.md`, `CHN_1955_agrarian_effects_DRAFT.json`.
**Назначение:** объяснить какие величины являются существующими государственными полями, какие — мониторингом процессов и как они фиксируются при судействе. Никаких фактических показаний 1955 года здесь не подтверждено.

## 1. Уже имеющиеся в каноническом `countries/CHN.json.economy.stats`

- `gdp_growth_pct` — фактическая годовая экспертная ставка роста реального ВВП. Сценарные `+0.2` п.п. (1955), `+1.0` (1956), `+1.5` (1957), `+1.6` (1958), `+1.2` (1959), `+0.6` (1960) не записываются автоматически: при ежегодном пересчёте выбирается итоговая ставка один раз на базе изменившегося мира, без двойного эффекта уже учтённой аграрной продукции.
- `gdp_real_billion_2011_intl` — уровень ВВП по ППС в международных долларах 2011 года; рассчитать после определения макроэкономики. НЕ конвертировать в G$ бюджет.
- `agriculture_share_pct`, `industry_share_pct`, `services_share_pct` — доли отраслей, обновлять по фактической структуре, не автоматически из роста сельского производства.
- `institutional_capacity_index` — в 1955 старт 48, возможный разовый +0.1 при доказанных институциональных проверках. Каждая будущая дельта применяется ОДИН раз с собственным `effect_id`.
- `corruption_exposure_index` — в 1955 старт 59, дельта за 1955 = 0; более позднее уменьшение не гарантировано.
- `real_household_income_index` — общий национальный индекс, старт 100, предложено до 100.4 за 1955 при подтверждении. НЕ равен отдельному сельскому реальному доходу.
- `fiscal_spend_economy_billion`, `fiscal_spend_admin_billion`, `fiscal_spend_social_billion`, `fiscal_spending_total_billion`, `fiscal_budget_balance_billion` — только после утверждения и финансирования. Проект организационного запуска до 0.600 млрд G$; смета не проводка.
- `exports_billion`, `imports_billion`, `reserves_billion`, `population`, `military.active_personnel` — непосредственно из этого постановления дельта 1955 года не подтверждена.

## 2. Новые контрольные метрики: их НЕТ как отдельных официальных `economy.stats` полей в стартовом JSON

Они хранятся в проекте `annual_scenario_if_conditions_met[YYYY]` как **цели/сценарии**, а после утверждения политики должны отслеживаться во вложенных `active_processes[].monitoring_metrics` с результатами `observations_by_year`, а не как произвольно добавленные поля `economy.stats`. Поле `monitoring_metrics` — **предлагаемая будущая структура хранения**, пока отсутствующая в каноническом CHN JSON.

| Имя метрики | Единицы и определение | Где вести |
| --- | --- | --- |
| `agriculture_growth_extra_pp` | Дополнительные процентные пункты годового роста реальной аграрной добавленной стоимости против согласованной фоновой траектории; сценарий не является наблюдением | Экономический расчёт вердикта + наблюдение в главном процессе |
| `rural_real_household_income_advantage_pct_vs_no_reform` | Кумулятивная разница среднего реального располагаемого денежного и натурального дохода сельской семьи относительно контрфакта **того же года**, а не рост каждый год | Главный процесс: период, методика дефлятирования, `scenario_target` отдельно от `verified_actual` |
| `national_real_household_income_advantage_pct_vs_no_reform` | Кумулятивная общенациональная контрфактическая разница; только после проверки переводится в индекс `real_household_income_index` | Главный процесс + разовый госиндекс |

| `rural_workshops_operating` | Действительно работающие мастерские и кооперативные предприятия; отдельно дата начала их 18-месячных налоговых льгот | Подпрограмма сельской промышленности |

## 3. Правило сценарий → факт → эффект

Хранить на будущий год две независимые записи для каждой метрики:
- `scenario_target` — судейский ориентир (например, `35%` уездов в 1956-м), **не изменяет состояние**.
- `verified_actual` — реальная игровая оценка после проверки конкретных мер, NPC, расходов, сбоев и утверждения администратором; первоначально `null`.

Пример целевого формата после утверждения (НЕ существует пока в стране):
```json
{
  "process_id": "CHN-1955-AGRARIAN-POLICY-TURN",
  "monitoring_metrics": {
    "counties_where_rights_and_procurement_enforcement_verified_share_pct": {
      "unit": "pct_of_counties",
      "baseline": null,
      "scenario_targets": {"1955": 12, "1956": 35},
      "observations_by_year": {
        "1955": {
          "verified_actual": null,
          "verification_status": "PENDING_ADMIN_APPROVAL",
          "source_decision_id": "INTAKE-1955-CHN-AGR-01"
        }
      }
    }
  },
  "last_effect_year": null,
  "effect_history": []
}
```

После окончательного решения государственная модель получит **новые `active_processes`** с этими наблюдениями и обязательствами. В следующем году судья читает процессы, проверяет действия и расчёты, регистрирует новые уникальные `effect_id`, применяет фактическую годовую дельту один раз и обновляет `last_effect_year`.

## 4. Ограничения точности

Стартовый государственный JSON не содержит самостоятельных абсолютных объёмов зерна, фактической доли семейных договоров, численности рабочих машиносчётных станций, портфеля сельских кредитов или достоверной статистики сельских доходов. Эти показатели являются **сценарными оценками для подготовки судейского решения**, не историческими измерениями и не подтверждёнными фактами 1955 года. Их не следует создавать точными значениями без отдельного судейского основания.

Отдельная связь с действующим `CHN-HIST-01`: первая пятилетка не отменяется и не даёт дублирующего бонуса. Согласованный исторический исход Тайваньского кризиса — отдельное мировое решение, не часть аграрной программы.
