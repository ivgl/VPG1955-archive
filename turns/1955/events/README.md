Здесь находятся только тексты, полученные из доступных источников. **Публикация в архиве не утверждает ивент и не изменяет состояние игры.**

В `taiwan/` сохранены четыре текста: общая новость EBN, дипломатическая заметка КНР, две закрытые заметки США. Военная закрытая заметка КНР исключена по указанию администратора.

**Не найдены:** отдельный комплект 12 стартовых событий по странам и первый исходный ивент по Алжиру. Не заменять их календарём исторических событий-кандидатов или стартовыми JSON.

Все метки закрытости означают предназначенную аудиторию, но не создают отдельные GitHub-права; доступ имеет каждый участник приватного репозитория.
